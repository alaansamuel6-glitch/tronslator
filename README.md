# tronslator
Веб-переводчик на Flask с интеграцией Google Translate и gTTS. Поддерживает 9 языков: русский, английский, французский, немецкий, испанский, итальянский, японский, корейский, арабский. Реализован голосовой ввод через Web Speech API с автоматической очисткой поля. Функция озвучивания текста и копирования результата. Адаптивный дизайн.
